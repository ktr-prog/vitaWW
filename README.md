# vitaWW

A native PlayStation Vita port of *Animal Crossing: Wild World*, built from the DS decompilation.

**Work in progress. Not in a playable state yet.**


## Features

- Vita native 960x544 resolution (30:17 Widescreen)
- Adapted to displays 59.94 Hz refresh (~60 FPS)
- Pixel-Perfect 2D rendering
- Camera Controls
- Adapted to single screen
